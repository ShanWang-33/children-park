第一章 · IP 故事

「我在这里等你很久啦」

象当当在深圳市儿童公园的大象滑梯旁等了很久很久。

它听见远方传来的笑声,听见孩子们叫它的名字 ——「当当!当当!」

于是,它从童年记忆里慢慢醒来,戴上小蓝帽,系好绿围巾,尾巴别上一朵粉色的簕杜鹃花,走出大象滑梯,迎接每一个回来的、第一次来的小朋友。

「我在这里等你很久啦。今天,我们一起开园好吗?」

象当当不是普通的吉祥物 —— 它代表着深圳几代孩子的童年记忆,代表着儿童公园从「记忆中的老地方」到「新一代孩子的新家园」的回归与新生。

第三章 · 仪式流程

四幕叙事 — 20 分钟开园仪式

以「象当当呼唤 → 记忆回归 → 唤醒公园 → 当当开园铃启动」为核心叙事主线。

第一幕
象当当苏醒 · 主持人开场
孩子们一起喊「当当!当当!」,象当当人偶缓缓出现,童声朗读象当当的信。
第二幕
记忆回归 ·「我们回来啦!」
当年家长 / 当下父母 / 第一次来的小朋友三组家庭代表上台,与象当当击掌,共同喊出「象当当,我们回来啦!」
第三幕
唤醒公园 · 象当当 IP 亮相
妇联儿童音乐演出,承接老朋友、唤醒新朋友,象当当 IP 正式亮相。
第四幕
当当开园铃启动
领导嘉宾与象当当共同启动「当当开园铃」 — 撒花、气球释放、音乐高潮,全场欢呼,儿童合唱。

第四章 · 冒险路线

象当当 3 站冒险地图

每一站都有一个低门槛、可拍照、可盖章的任务 — 路线不只是分流人群,也是把「儿童友好、生态守护、亲子共享」落到具体体验里的方法。

S1
大象滑梯记忆站
原大象滑梯区
家长和孩子共同拍照,设置「我小时候也玩过这里」的亲子留言墙
S2
簕杜鹃花园站
花园区 / 景观花带
认识深圳市花,制作花朵贴纸和手工毛线饰品
S3
勇敢探索站
体能挑战区
儿童挑战简单体能小游戏,如平衡木、跳格子、勇气通道

完成 3 站盖章 → 兑换「象当当冰箱贴」或「簕杜鹃种子卡」 · 你已成为象当当小小守护者!
